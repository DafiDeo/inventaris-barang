Proyek ETS Versi 1.0

{{ nama_sistem }} adalah aplikasi web yang dibangun untuk membantu petugas gudang dalam mengelola data inventaris barang secara terpusat dan teratur. Sistem ini menyediakan pencatatan master data barang, pemantauan jumlah dan kondisi barang, pencatatan transaksi barang masuk dan keluar, serta penyajian laporan inventaris yang siap dicetak.

Seluruh data tersimpan secara lokal menggunakan database SQLite sehingga aplikasi dapat dijalankan tanpa layanan server tambahan. Antarmuka dibangun dengan Flask, Jinja2, dan Bootstrap 5 agar ringan, responsif, dan mudah digunakan baik pada komputer, tablet, maupun ponsel.

Tujuan Sistem
  • Mempermudah petugas mencatat dan mengelola data inventaris barang dalam satu sistem terpusat.
  • Memantau jumlah stok dan kondisi barang (Baik, Rusak Ringan, Rusak Berat) secara real-time.
  • Menghindari kesalahan pencatatan stok melalui validasi input dan transaksi otomatis.
  • Menyediakan laporan inventaris yang cepat disusun dan siap dicetak untuk kebutuhan administrasi.
  • Membantu pengambilan keputusan, misalnya melalui informasi barang dengan stok rendah.
Fungsi Utama Sistem
  • Dashboard ringkasan jumlah barang, kondisi barang, serta barang masuk dan keluar.
  • Manajemen data barang: tambah, edit, hapus, cari, dan filter.
  • Pencatatan transaksi barang masuk dan barang keluar dengan perubahan stok otomatis.
  • Laporan inventaris lengkap dengan ringkasan kondisi dan riwayat transaksi.
  • Halaman profil sistem dan panduan penggunaan untuk memudahkan pengguna baru.
Teknologi yang Digunakan
Python 3 + Flask SQLite Jinja2 Bootstrap 5 Bootstrap Icons HTML5 + CSS3 + JavaScript Visual Studio Code

Bantuan & Panduan Penggunaan

Ikuti langkah-langkah berikut untuk menggunakan sistem dengan benar.

Dashboard adalah halaman pertama yang tampil saat sistem dibuka. Halaman ini menampilkan ringkasan total jenis dan unit barang, jumlah barang masuk dan keluar, ringkasan kondisi barang, daftar barang dengan stok rendah, serta tabel barang yang terbaru ditambahkan.

  1. Gunakan menu di sidebar kiri untuk berpindah halaman.
  2. Klik Manajemen Data, Transaksi, atau Laporan untuk membuka submenu.
  3. Tombol hamburger (☰) pada navbar atas berfungsi menyembunyikan atau menampilkan sidebar. Pada ponsel, sidebar terbuka di atas konten.
  4. Pesan notifikasi hijau/merah di bagian atas konten akan muncul setelah setiap aksi dan hilang otomatis beberapa detik kemudian.

Seluruh pengelolaan data barang berada di menu Manajemen Data.

Menambah barang baru:

  1. Buka menu Manajemen Data → Tambah Barang (atau tombol "Tambah Barang" pada halaman Data Barang).
  2. Isi kode barang, nama barang, kategori, lokasi, jumlah stok, kondisi, dan tanggal pencatatan. Kolom bertanda * wajib diisi.
  3. Klik Simpan. Notifikasi hijau akan muncul jika berhasil.

Mengedit dan menghapus barang:

  1. Buka halaman Data Barang, lalu klik tombol ikon pensil pada baris barang yang ingin diubah, perbaiki datanya, dan klik "Simpan Perubahan".
  2. Untuk menghapus, klik tombol ikon tempat sampah, konfirmasi pada jendela modal yang muncul, lalu klik "Ya, Hapus".

Mencari dan memfilter:

  1. Ketik nama atau kode barang pada kolom pencarian, pilih kategori dan/atau kondisi, lalu klik Terapkan.
  2. Klik tombol X untuk mengosongkan kembali pencarian dan filter.

Fitur ini digunakan setiap kali barang diterima, misalnya dari supplier atau pengadaan baru. Stok barang akan bertambah otomatis sesuai jumlah yang dicatat.

  1. Buka menu Transaksi → Barang Masuk.
  2. Pilih barang pada daftar. Informasi stok saat ini akan ditampilkan di bawah pilihan.
  3. Isi jumlah barang yang diterima (angka lebih dari 0), tanggal transaksi, dan keterangan bila perlu.
  4. Klik Simpan Transaksi Barang Masuk. Riwayat di sebelah kanan langsung diperbarui.
  5. Periksa stok terbaru pada halaman Data Barang untuk memastikan pencatatan berhasil.

Fitur ini digunakan setiap kali barang dikeluarkan, misalnya dipakai atau dipinjam. Sistem otomatis mengurangi stok dan akan menolak transaksi jika jumlah keluar melebihi stok yang tersedia.

  1. Buka menu Transaksi → Barang Keluar.
  2. Pilih barang dan perhatikan informasi stok tersedia yang muncul di bawah pilihan.
  3. Isi jumlah barang yang keluar dengan nilai tidak melebihi stok tersedia, lalu isi tanggal dan keterangan.
  4. Klik Simpan Transaksi Barang Keluar. Jika stok tidak mencukupi, notifikasi merah akan muncul dan transaksi tidak tersimpan.
  5. Riwayat transaksi keluar dapat dilihat pada tabel di sebelah kanan maupun pada halaman Laporan.

Halaman Laporan → Laporan Inventaris menyajikan ringkasan kondisi barang, daftar seluruh barang, dan riwayat transaksi masuk/keluar.

  1. Gunakan filter kategori, kondisi, jenis transaksi, serta rentang tanggal untuk menyaring isi laporan, lalu klik Terapkan.
  2. Klik Cetak Laporan untuk membuka dialog cetak browser. Sidebar, navbar, dan tombol otomatis disembunyikan pada hasil cetak.
  3. Pada dialog cetak, pilih "Save as PDF" jika ingin menyimpan laporan sebagai berkas PDF.
